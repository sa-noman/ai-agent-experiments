# Research Agent

## Overview

A compact research-assistant experiment that organizes supplied text into a topic, summary, findings, facts, entities, and follow-up questions.

## Features

- Uses only the provided source
- Separates findings, concrete facts, and further questions
- Deterministic local fallback
- Optional OpenAI integration

## How It Works

Local mode ranks source sentences, prioritizes sentences with concrete quantities for the facts section, extracts capitalized entities, and adds generic research questions that do not assert new facts. Live mode is isolated in `openai_provider.py`.

## Installation

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Configuration

Set `OPENAI_API_KEY` in an uncommitted `.env` file only for live output. `OPENAI_MODEL` is optional. Local mode requires no key.

## Usage

```bash
python 02-research-agent/app.py 02-research-agent/sample_input.txt
python 02-research-agent/app.py 02-research-agent/sample_input.txt --use-llm
```

## Example

Run the first command to reproduce `sample_output.txt`. The saved local result is labeled **Example Output** because it was not generated by a live model.

## Limitations

This tool organizes provided text; it does not browse, verify claims, compare external sources, or perform autonomous research. Heuristic sentence ranking and entity extraction may miss nuance.
